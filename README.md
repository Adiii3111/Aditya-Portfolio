# Aditya Kadlabal Sripad — Portfolio

Personal portfolio of **Aditya Kadlabal Sripad**, engineer, researcher, and analyst working across healthcare, supply chains, and analytics. M.S. Engineering Management, Northeastern University (2026).

From Bengaluru to Boston — and beyond.

**Live site:** https://adiii3111.github.io/Aditya-Portfolio/

## What's inside

- **Journey** — an interactive map from Bengaluru to Boston to Willmar, Minnesota
- **Experience** — Vaxxinova US, Greaves Electric Mobility, Nakshatra Agencies, MTR Foods, NoBroker.com
- **Project MERCURY demo** — a 15-module illustrative supply chain decision-assist demo.
  *Built entirely on synthetic data; not the original MERCURY system.*
- **Selected projects** and **research** — including the Winter Simulation Conference 2026 paper on multi-echelon perishable blood supply chains
- **The Lab** — hands-on experiments: route optimization, patient flow, a blood bank challenge, and a pace calculator
- **AgileFlowSprinter** — the running community Aditya founded

## Built with

Next.js 16 · React 19 · TypeScript · hand-written SVG and Canvas graphics (no charting libraries)

## Run locally

```bash
npm install
npm run dev      # on Windows PowerShell: npm.cmd run dev
```

Then open http://localhost:3000.

All site copy lives in `app/content.ts`.
